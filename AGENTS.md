# Which Deal's Better? project rules

These rules apply to all future work in this repository.

1. Production deployment is GitHub-connected Cloudflare Pages only.
2. Never create or use ChatGPT Preview or OpenSite deployments.
3. Never attach `whichdealsbetter.com` to a ChatGPT-managed Worker.
4. Do not modify `D:\Projects\GroundworkCalc` or `D:\Projects\FloorsCalc`.
5. The contact form uses Cloudflare Pages Functions and the Brevo REST API.
6. Never hardcode API keys, analytics IDs, AdSense IDs, or other secrets.
7. Configure shared sitewide services centrally.
8. Calculator inputs remain local in the browser and are never sent to a server.
9. Keep the site simple, mobile-first, fast, and low-maintenance.
10. Run tests, Astro check, and a production build after meaningful changes.
11. Preserve accessibility and SEO.
12. Do not add unnecessary frameworks, dependencies, accounts, databases, or APIs.
13. Do not deploy unless explicitly instructed.
14. Do not force-push or rewrite Git history unless explicitly instructed.
